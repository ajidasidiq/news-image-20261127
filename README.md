A one-page newspaper front page summing up the world news of Friday 27 November 2026: the Thanksgiving storm that postponed New York's 100th Macy's parade, Zelenskyy's warning of a new Russian grid attack and the EU's split over a 45bn euro Ukraine loan, the Bangkok refinery blast, the Cairo tanker fire that killed 31, Black Friday, and a sports ticker. `main.py` (Python 3.13, standard library only) draws the whole 1024x1024 image from scratch — a built-in 5x7 bitmap font plus vector pictograms — and writes it to `/output/entry.png`. No network, no assets, fully deterministic.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
